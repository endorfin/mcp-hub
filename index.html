Server importieren

    

      JSON im Format von Claude Desktop, Cursor & Co. einfügen – entweder mit mcpServers oder direkt die Server-Objekte. Bestehende Einträge gleichen Namens werden überschrieben. Lokale Befehle (command) und URLs (url, optional mit headers) werden übernommen.
      
      

    

    

      
      
    

  




  
Profile

  

    Jedes Profil hat einen eigenen Endpunkt. Ein Client, der dort angebunden ist, sieht immer die Server und Tools dieses Profils – unabhängig davon, welches Profil oben aktiv ist. Server, die im Hub ausgeschaltet sind, fehlen allerdings auch dort.
    

  

  




  

    
Tools

    

      Abgewählte Tools blendet der Hub aus und lehnt Aufrufe ab. Der Server selbst wird nicht neu gestartet. Verbundene Clients bekommen die neue Liste automatisch, Claude Desktop erst nach einem Neustart.
