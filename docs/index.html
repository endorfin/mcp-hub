          One hub instead of six config files

          Every MCP client keeps its own list of servers. Add a server and you edit four config files; rotate a token and you hunt it down in all of them, usually in plain text. MCP Hub turns that around: servers live in one place, secrets stay in the keychain, and every client gets a single entry pointing at the hub.

          Connect every client with one click

          Settings → Clients finds Claude Code, Claude Desktop, Codex, Cursor, VS Code and Copilot CLI on your machine and adds the hub to each, writing a backup of the file first. By hand, every client needs exactly one entry.

          
          
          
        
          
      
          

      
          
        
          
          
          Bring your existing servers along
          
          
          Paste what you already have: JSON from Claude, Cursor or VS Code, TOML from Codex, or mcp add commands. The hub detects the format, shows a preview, and can remove the servers from the old client in the same step.

          Compact mode: 300 tokens instead of 60,000
          
          
          Clients load every tool definition into their context on every request. At /mcp/compact they get three tools instead and find the rest by searching, locally, without an index or a model. Each client picks its mode by its URL.
          
        
          
        
          
          
          
            
          
              
          All tools on /mcp≈ 60,000 tokens
          
              
          Compact on /mcp/compact≈ 300 tokens
          
            
          
            
          Tool definitions per request with 200 tools, as in the README.
          
            
          
              
          search_toolsfinds tools by what you want to do
          
              
          describe_toolfull description and input schema of one tool
          
              
          call_toolcalls a tool by name with its arguments
          
            
          
          
          
        
          
      
          

      
          
        
          
          
          Profiles, each with its own endpoint
          
          
          A profile remembers which servers and tools are on. Switch in one click and connected clients get the new tool list live. Every profile also has its own URL, so Copilot can work with “Frontend” only while Claude Code gets everything.

          Management, test bench and log in one window
          
        
          Servers with tags, status and usage; an inspector to call any tool by hand; a call log that shows which client called what, how long it took and what came back.
          
      
          
      
          
      
          
        
          Restarts on its own
          Crashed servers come back after 2, 4, 8, 16 and 32 seconds; clients hear about it through list_changed.
          
        
          Live updates
          Changes reach Claude Code, VS Code and Claude Desktop, through the bundled bridge, without reconnecting.
          
        
          Inspector
          Connect to a server directly and call tools, resources and prompts with form or JSON input.
          
        
          Statistics
          Calls, error rate, median and p95 per server, and the slowest tools, over the last 5,000 calls.
          
        
          Local only
          Listens on 127.0.0.1 and rejects foreign origins and DNS rebinding.
          
        
          Updates with one click
          A chip in the header shows a new release; the hub updates and restarts itself.
          
        
          Starts at login
          LaunchAgent on macOS, systemd user service on Linux, scheduled task on Windows.
          
        
          No baggage
          Python standard library, one process, no build step. Tested in CI on all three platforms.
          
      
          
    
          
  
          

  
          
    
          
      
          
        
          Running in two minutes
          
        
          Python 3.11 or newer is all it needs. Nothing to build, nothing to install with pip.
          
      
          
      
            
        
          1. 
          
            Install and run
            
          
            Clone the repository or download the latest release, then open the interface at http://127.0.0.1:4747.
            
          
            git clone https://github.com/endorfin/mcp-hub.git
cd mcp-hub && python3 app.py
            
        
            2. 
        
          2. 
          
            Add servers
            
          
            Click + → “Import…” and pick an installed client to take over its servers, or paste an existing configuration. “Add server…” creates one by hand.
            
        
            3. 
        
          3. 
          
            Connect your clients
            
          
            Settings → Clients → “Connect clients”, or add the one entry by hand:
            
          
            claude mcp add --scope user --transport http mcp-hub http://127.0.0.1:4747/mcp
            
        
            4. 
        
          4. 
          
            Start at login
            
          
            Stop the hub from step 1 and register it, so your clients find it after a reboot.
            
          
            
          
            
        
            5. 
      
          
    
          
  
          

  
          
    
          
      
          One entry per client. Everything else lives in the hub.
